💻 Part 1 · Frontend Architecture

สถาปัตยกรรมส่วนหน้าบ้าน (Frontend Tech Stack)

การออกแบบ User Interface ระดับพรีเมียม ตอบสนองรวดเร็วแบบ Single Page Application (SPA)

⚛️

React 19 Component Architecture

พัฒนาด้วย React 19 แบ่ง UI ออกเป็นโมดูลย่อยที่นำกลับมาใช้ซ้ำได้ (Modular Components) จัดการ Client State ด้วย React Hooks ให้การสลับ Role และการเปิด Accordion ตอบสนองทันทีโดยไม่ต้องโหลดหน้าใหม่

🎨

Tailwind CSS v4 & Glassmorphism

ใช้ประโยชน์จาก Tailwind CSS v4 Engine ทำงานร่วมกับ CSS Variables สร้างธีมสตูดิโอดาร์กโมด (Dark Slate / Amber Accent) พร้อมเอฟเฟกต์ Glassmorphism แบบโปร่งแสงและ Micro-animations เมื่อ Hover

⚡

Vite 8 Build Tooling

คอมไพล์โค้ดด้วย Vite 8 รองรับ Hot Module Replacement (HMR) แบบเร็วพิเศษ เพิ่มความเร็วในการประมวลผล Assets และมี Bundle Size ขนาดเล็ก ทำให้ผู้ใช้โหลดหน้าเว็บได้อย่างรวดเร็วในทุกอุปกรณ์

👤 Frontend Experience · Customer

หน้าบ้านฝั่งลูกค้า (Customer Portal UI)

ประสบการณ์การแจ้งซ่อมที่ง่ายดาย และการติดตามสถานะงาน 6 ลำดับขั้นแบบเรียลไทม์

🌟 องค์ประกอบ UI ฝั่งลูกค้า

  • ✓ Hero Carousel: แสดงสไลด์ภาพและบริการรับซ่อม PC พร้อมระบบ Auto-play
  • ✓ New Repair Modal: ฟอร์มกรอก Serial Number, อาการเสีย, อัปโหลดรูปสภาพเครื่อง
  • ✓ Delivery Selector: สลับเลือกระหว่าง นำเครื่องมาส่งเอง (Drop-off) หรือส่งพัสดุ (Mail-in)
  • ✓ 6-Stage Timeline Accordion: แผงไทม์ไลน์สถานะ 6 ขั้นที่กางดูรายละเอียดและโน้ตจากช่างได้
  • ✓ Rating & Complaint UI: ฟอร์มให้ดาว 1-5 ดาว และช่องยื่นเรื่องร้องเรียนพร้อมแนบหลักฐาน
✨ UI Design Highlight

Visual Timeline Indicator

ไทม์ไลน์ 6 ขั้นตอนถูกออกแบบด้วยสีและไอคอนที่แสดงความคืบหน้าอย่างชัดเจน:
Submitted ➔ Received ➔ Diagnosing ➔ Fixing ➔ Waiting Part ➔ Finished

ลูกค้าไม่ต้องเดาว่าเครื่องอยู่ขั้นตอนไหน UI จะไฮไลต์สถานะปัจจุบันและแสดงเวลาที่ช่างอัปเดตล่าสุดโดยอัตโนมัติ

🔧 Frontend Experience · Staff & Admin

หน้าบ้านฝั่งช่างและผู้ดูแลระบบ (Staff & Operations UI)

Workspace สำหรับช่างซ่อม และแดชบอร์ดกระจายงานแบบ Kanban สำหรับผู้จัดการ

🛠️

Technician Workspace UI

• Stat Counters: การ์ดสรุปตัวเลขงานรอซ่อม, รออะไหล่, และงานเสร็จสิ้น
• Interactive 6-Status Selector: ปุ่มกดเลือกเปลี่ยนสถานะงานในคลิกเดียว
• Diagnostic Note Box: ช่องพิมพ์บันทึกเชิงเทคนิคเพื่อส่งต่อเป็นอีเมลอัปเดตถึงลูกค้า
• Assigned Filter: ฟิลเตอร์แสดงเฉพาะงานที่ช่างคนนั้นได้รับมอบหมาย

📊

Admin Operations & Workload Board

• Weekly Repair Volume Chart: กราฟแท่งแสดงปริมาณงานซ่อม 7 วันย้อนหลัง
• Team Workload Kanban: เลนกระจายงานแบบ Dispatch แสดง Workload Capacity ของช่างแต่ละคน (เช่น 2/3)
• Account Directory: ตารางจัดการบัญชี เพิ่ม/ปิดการใช้งานผู้ใช้ และรีเซ็ตรหัสผ่าน
• Feedback Inbox: แผงรับข้อร้องเรียนพร้อมฟอร์มพิมพ์ตอบกลับส่งตรงถึงลูกค้า

⚙️ Part 2 · Backend Engineering

สถาปัตยกรรมส่วนหลังบ้าน (Backend Tech Stack)

ขุมพลังการประมวลผล Business Logic, Data Persistence และ API Endpoints ด้วย Laravel 13

🐘

Laravel 13 & PHP 8.5

ใช้เฟรมเวิร์ก Laravel 13 โครงสร้างแบบ MVC มี Dependency Injection Container และ Routing Engine ที่มีประสิทธิภาพสูง จัดการ Business Logic ของงานซ่อมอย่างรัดกุม

🔌

RESTful API Design

ออกแบบ API ตามมาตรฐาน RESTful แบ่งกลุ่มชัดเจน: /api/auth, /api/repairs, /api/feedback, /api/accounts และ /api/smtp รองรับการส่งและรับข้อมูลแบบ JSON

🛡️

Role-Based Access (RBAC)

มีระบบป้องกันสิทธิ์การเข้าถึงข้อมูล ลูกค้าเข้าถึงได้เฉพาะใบแจ้งซ่อมของตนเอง ขณะที่ช่างและแอดมินมีสิทธิ์ตามระดับหน้าที่ พร้อมป้องกัน CSRF และ Data Validation ทุกขั้นตอน

🗄️ Database & Models · Backend

โครงสร้างฐานข้อมูลและโมเดล (Database & Eloquent ORM)

การออกแบบ Schema และความสัมพันธ์ของข้อมูลแบบ Relational Database ผ่าน SQLite

👤

User Model

เก็บข้อมูลผู้ใช้งาน, รหัสผ่าน (Bcrypt Hash), บทบาท (Customer, Technician, Admin, Manager), เบอร์โทร และสถานะบัญชี

📋

Repair Model

ตารางหลักเก็บเลข Serial, อาการเสีย, สถานะ 6 สเต็ป, วิธีส่งเครื่อง, รูปประกอบ, ช่างที่รับผิดชอบ (Foreign Key) และโน้ตการตรวจเช็ค

💬

Feedback Model

เก็บคะแนนดาวรีวิว (1-5), รายละเอียดข้อร้องเรียน, รูปหลักฐาน, และข้อความตอบกลับจากผู้บริหาร (Admin Reply)

⚙️

SmtpSetting Model

เก็บบันทึกการตั้งค่า Mail Server (Host, Port, Username, TLS/SSL, Driver) เพื่อรองรับการปรับแต่งเมลสดผ่านหน้าเว็บ

💡 ORM Advantage: ใช้ Laravel Eloquent ORM เชื่อมโยงความสัมพันธ์ User hasMany Repairs และ Repair belongsTo Technician ทำให้ Query ข้อมูลได้อย่างมีประสิทธิภาพและปลอดภัยจากการโจมตี SQL Injection
📧 Core Backend Engine

ระบบแจ้งเตือนอีเมลอัตโนมัติ (Automated SMTP Engine)

การส่งอีเมลแบบ Event-driven ผูกกับวงจรการซ่อม พร้อมบันทึกประวัติแบบ Audit Logs

⚡ Automated Email Triggers

1. Ticket Created: ส่งอีเมลยืนยันการรับแจ้งซ่อม พร้อมคำแนะนำการส่งเครื่องถึงลูกค้า
2. Status Updated: ส่งอีเมลแจ้งเตือนลูกค้าทันทีเมื่อช่างเปลี่ยนสถานะหรือใส่ Workshop Note
3. Work Assigned: ยิงอีเมลเตือนช่างเมื่อแอดมินมอบหมายงานซ่อมเครื่องใหม่ให้
4. Complaint Reply: ส่งคำชี้แจงจากแอดมินเข้าสู่อีเมลลูกค้าโดยตรงเมื่อมีการตอบข้อร้องเรียน

🛠️ คุณสมบัติของระบบ SMTP ใน Fixsmith

  • ✓ Dynamic Configuration: เปลี่ยน Mail Host และ Port ได้สดๆ ผ่าน UI ไม่ต้องแก้โค้ด
  • ✓ Multi-Provider: รองรับ Mailtrap (ทดสอบ), Gmail (App Password), Sendgrid, Brevo
  • ✓ Offline Log Mode: บันทึกเนื้อหาอีเมลลง storage/logs/laravel.log ทำให้เดโมได้แม้ออฟไลน์
  • ✓ Audit Logs: มีแท็บบันทึกประวัติการส่งอีเมลย้อนหลัง ตรวจสอบความถูกต้องได้ทุกรายการ
